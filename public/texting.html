Texting setup

Texts are sent through Twilio. Whoever runs this site sets it up once; after that, anyone signed in can tick "Text to" in Settings.

  1. Make a Twilio account and upgrade it (add a payment method and a starting balance). A free trial can only send Twilio's own sample texts, not reminders.
  2. Get a number that can text US phones, and register it. Either:
    • a toll-free number, then Toll-Free Verification (free; as an individual, pick Sole Proprietor), or
    • a local number, then A2P 10DLC registration as a Sole Proprietor (small one-time fees and a monthly fee; Twilio texts you a code to confirm).
    Texts won't arrive until it's approved, usually within days.
  3. In py/wrangler.toml, fill in TWILIO_ACCOUNT_SID (from the Twilio console, starts with AC) and TWILIO_FROM (your Twilio number, like +18885551234), and remove the # in front of both.
  4. Make an API key: in the Twilio console, API keys & tokens → Create API key, type Standard. Store its two parts as secrets, from the py folder (copy each one, then run):
    pbpaste | npx wrangler secret put TWILIO_API_KEY (the key's SID, starts with SK)
    pbpaste | npx wrangler secret put TWILIO_API_SECRET (the secret, shown only once)
  5. List the numbers this site may text or call at all (just yours, to start), as a secret: pbpaste | npx wrangler secret put PHONE_NUMBERS (like +15035551234; separate several with commas). Any other number is refused.
  6. Deploy. Then in Settings, tap "(need to set this up?)" next to "Text to", save your number, then press Test.
